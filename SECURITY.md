# Security

Please do not publish ROMs, save files, signing keys, passwords, or private project exports in an issue.

For a suspected security problem in the editor or Android wrapper, use a private GitHub security advisory if the repository enables them. Otherwise contact the repository maintainer privately before public disclosure and include a minimal reproduction that contains no confidential files.

Security reports are most useful when they include the affected version, platform, reproduction steps, impact, and a proposed mitigation if known.
